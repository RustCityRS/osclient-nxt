# osclient-nxt

The tree is rebuilt from [osclient-216-mac](https://github.com/RustCityRS/osclient-nxt/blob/main/_tools/osclient-216-mac) (Mach-O x86_64, build OS1669) with Ghidra 12.2. Names, signatures, file placement, inheritance and virtual order come from the binary's symbols, debug map and vtables; bodies come from Ghidra's decompiler and are rewritten into ordinary C++.
